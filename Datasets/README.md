# GPU 加速研究：数据资源

本目录为 `research/gpu-acceleration-clean` 分支保留数据资源。
原始数据是独立文件副本，不是指向旧工作区的链接，也不与原文件共享 inode。
复制完成后已逐文件核对 SHA256。旧实现、训练结果及实验参数不带入本分支。

## 清单

- `TSP/`：现存的原始 TSP 数据与标签／参考路径。原始数据只在本地保留，不提交 Git。
- `manifest.json`：原有研究登记的 82 个文件的历史清单，保持原内容。它不是本轮冻结的数据划分，也不覆盖全部现存资源。
- `SHA256SUMS`：本次复制的原始文件及历史 manifest 的内容校验值。
- `provenance.json`：来源目录、来源工作区提交、复制方法、核验方法和资源数量。

在本目录执行完整内容检查：

```sh
sha256sum -c SHA256SUMS
```

## 本轮研究的边界

本分支以 GPU 加速研究为目标。目前只初始化资源，不启动训练或性能实验。
工作负载、训练／验证／测试划分、随机种子、数值语义和计时边界均需重新定义并冻结。
不自动沿用旧 manifest 中的使用许可、排除规则或实验规模。

这些数据此前已用于研究。文件复制和哈希一致不意味着它们是未见数据。
需要独立确认时，应检查历史使用记录和内容重复，必要时建立新的确认集。
参考路径的来源和最优性应逐类核验，不能把启发式参考解一概称为已证明最优解。
