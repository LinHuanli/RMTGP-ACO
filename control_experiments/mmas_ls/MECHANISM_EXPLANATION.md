# MMAS 组件对 GP 增益的影响：执行协议

本协议执行 2026-09-18 确认的方案。只研究已有固定表达式，不重新训练或选择模型。

## 1. 问题与已有证据

问题是：为什么 GP 对 MMAS + 2-opt 的增益不如对 AS + 2-opt 明显？先定位组件，再检验作用过程。
已有开发集实验最强的证据指向历史优良路径强化。关闭这一组件后，不使用 GP 的方法退化更多。
这不是关闭组件能够改进算法的证据，也不能单凭最终质量差证明功能重叠。

读者可见的表格和图例一律使用完整组件名称。原始任务编号只用于文件追溯，不作为科学解释。
统一报告“GP 带来的改进 = 不使用 GP 的 gap − 使用 GP 的 gap”，正值表示改善，单位是百分点。
gap 相对于可行参考路径，不声称参考路径已证明最优。

## 2. 冻结实验

共同设置：TSP500、32 只蚂蚁、5000 轮、构造与局部搜索候选数均为 20；每轮全部蚂蚁执行
ACOTSP 风格 2-opt。构造和信息素更新残差系数均为 1/3。AS 蒸发率为 0.5，MMAS 为 0.2。
六个表达式由原冻结清单指定，不因本轮结果替换。最终路径长度使用 CPU FP64 重算。

### 开发阶段

32 个冻结开发实例，5 个配对求解种子。AS 与 MMAS 各比较：全部本轮路径、本轮最优单路径、
固定全局日程历史单路径。另加 MMAS 原生配置，共七种条件。每种条件均执行六个表达式与
一个不使用 GP 的对照，共 7840 个逻辑求解。数值环境使用中心化 FP32，并通过逐型号验收。

首轮跨框架验收发现，500 条来源边的 FP32 顺序求和可积累均值误差。第二批次采用显式舍入的
补偿求和，终端数学定义、数据类型和误差阈值不变。原批次停止并保留；用真实失败输入和偏斜
分布增加回归验收。此数值实现与旧中心化实现在源码哈希和协议中明确区分，不混合结果。

固定全局日程的更新周期依次为 25、5、3、2、1，对应既有实现中的绝对轮次分段；历史时隙使用
历史全局最优路径，其余时隙使用本轮最优路径，不因重启改变日历。保留执行框架自己的其他配置。
每个状态采用原生影子来源的总沉积预算。多来源按路径长度倒数分配预算，不删除重复路径。
匹配的是同状态预算规则，不声称不同轨迹上的预算数值相同。

### 同状态干预

前 8 个开发实例、前 3 个求解种子，MMAS 不使用 GP 和三个自身训练的表达式作为状态生成者。
原数值实现与中心化 FP32 分别保存状态。第 1、100、250、500、1000、2500 轮保存局部搜索结束和
轮末状态。所有干预从完整状态出发，不用汇总指标重建状态。

每个轮末状态包含六个分支：原生来源下不使用 GP、只用构造树、只用更新树、使用两棵树；
仅本轮最优来源下不使用 GP、使用两棵树。每个分支续跑 500 轮，记录 1、25、100、500 轮结果，
时间输入分母仍为 5000。状态生成者是哪个表达式，不意味着对照状态要混入另一个表达式。
不使用 GP 的状态分别与三个表达式配对；GP 状态只与自身表达式配对。行为相同的分支计算去重。

局部搜索结束状态另做单次更新：来源为本轮最优、重启后最优、历史全局最优，分别开关更新树。
预算来自同一状态。比较真实沉积、蒸发后、沉积后、重启后信息素与固定上下文选择概率。
概率参考重算明确标为 CPU FP64，不冒充 GPU 逐位概率。

### 独立确认

已冻结的 128 个确认实例、10 个配对种子。MMAS 比较原生配置、关闭历史路径强化、关闭重启、
关闭信息素下界保护。AS 比较全部本轮路径、本轮最优单路径、固定日程历史单路径。
每种条件执行该框架三个固定表达式与不使用 GP 的对照，共 35840 个逻辑求解。
确认使用中心化 FP32，不把原实现的已知数值偏差认证为数学正确。
确认集不用于选择对照、表达式、采样轮次或效应阈值。

## 3. 统计与日志

实例是配对统计单位。先平均求解种子，再等权平均固定表达式；三个表达式另表报告。
旧数据保留原 18 项同时比较。确认预设 14 项比较：七种条件各自的 GP 增益；三个 MMAS
组件移除效应；AS 从全部路径到单条当前路径、从单条当前路径到历史路径的两个效应；
历史强化移除效应分别减去重启、下界移除效应。30,000 次实例配对 bootstrap max-t，
种子 2026091801，95% 同时区间，实际意义阈值 0.01 个百分点。

过程分析固定按 1–250、251–1000、1001–2500、2501–5000 轮汇总，并绘制完整时间曲线。
来源质量、真实路径重复、边重合、源内输出变化、预算归一化后的沉积差、固定上下文概率差、
局部搜索前后质量与多样性必须分别定义。新过程分析是事后探索，不追称预注册机制证据。
重启事件对齐曲线仅作条件描述。同状态分叉才能估计特定状态下的干预效果。

所有正式任务保存完整第三版诊断。只有小样本保存永久完整状态。记录源码、模型、数据、设备、
日程与恢复状态哈希。每型号先独立验收，再放行正式任务；失败不得改参数或绕过门禁。

## 4. 执行与交付

先发布现有结果的中文解释报告，再更新中间日志分析，最后纳入独立确认。报告按现象、实现、
组件干预、过程变化、同状态与反向验证、结论排列。数值核验和工程审计放附录。
新实验使用独立目录，不覆盖旧队列。资源范围沿用空闲 A5000、RTX 4000 Ada、A4000，后台
监控每 60 秒扫描。磁盘至少保留 150 GiB；预估空间不足时暂停，不自动降低记录精度或频率。
不启动新训练，不扩展到分布外数据，不预设最终一定由某个唯一组件解释。
