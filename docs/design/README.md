## 研究目标

在固定单树 GP-ACO 语义和搜索预算下，提高 **程序 × 实例 × 随机重复** 的大规模评估效率，缩短整代和完整训练时间。分别研究优化 CPU 与 GPU 的收益，并检验节省的计算时间是否能改善自动算法设计结果。

GP-ACO 是主要验证对象。方法可以面向其他具有可描述程序、输入特征和可访问搜索状态的 AAD 任务，但跨任务收益需要独立实验，不能由本案例直接外推。

## 固定边界

| 项目 | 本轮设定 |
|---|---|
| 算法表示 | 单棵状态转移树；当前完整 F1 函数集、十终端和常数；固定信息素更新 |
| 加速对象 | 整代种群评估和完整训练，不以单个 ACO 实例延迟为主目标 |
| 数值路径 | CPU/GPU 搜索、路径长度和适应度使用 FP32；无在线 CPU FP64 重算或审计回退 |
| 质量检查 | 候选锁定后，离线统一核算返回的最终测试路径；不重新求解，不反馈训练 |
| 主规模 | TSP100 与 TSP500；分别改变外层 P/B/R 与内层 n |
| 强对照 | 当前单树 FP32 CPU/GPU 版本、优化 CPU、通用张量及可适配的 GPU-GP 组合实现 |
| 方法范围 | 特征—程序联合优化、CPU 局部性/向量化、GPU 资源/状态感知执行 |
| 暂不扩展 | Multi-Tree、新信息素学习规则、核心低精度路线、多节点系统和任意 Python AAD 编译 |

默认主工作点：P=100、B=32、R=1、A=32、I=500、K=20、G=50；31 节点、深度 5。具体参数来源和单树改动见总计划。工程阈值和实验数量是预设默认值，在确认性实验前冻结，不是已获得的结果。

## 第一阶段交付

首先冻结数值和算法规范、科学预算、数据划分、随机流和计时边界；移植单树 FP32 的 CPU-Existing 与 GPU-Existing；完成 E00；再用 E01 定位真实成本并用 E02 复核历史现象。

这一步的交付应是可运行的强基线、状态快照、运行清单和诊断报告，而不是尚无测量依据的复杂自适应系统。M1/M2/M3 的实现优先级由这些证据决定。

## 结果判读原则

组件加速不等于完整训练加速；GPU 快于旧 GPU 不等于快于优化 CPU；吞吐提高不等于最终算法质量提高；跨 ACO 变体有效不等于任意 AAD 有效。

每项方法都规定支持、否定和证据不足的情形。编译成本抵消收益、固定配置已足够、GPU 与优化 CPU 接近、TSP500 现象未复现、等时间质量未改善，都有相应的缩减方法或限定结论方案。
